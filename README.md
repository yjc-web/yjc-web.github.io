## ⚡ All-in-One Synergy (유기적 업무 시너지)

FlowSuite의 도구들은 개별적으로도 강력하지만, 함께 사용할 때 완벽한 생산성 워크스테이션을 만듭니다:

```
[01. Reference]    OverlayPic   ─▶ 필요한 가이드 시안이나 데이터를 화면 위에 투명 핀 고정
[02. Automate]     AutoFlow RPA ─▶ 손이 많이 가는 반복 클릭과 시스템 입력을 노코드 순서도로 대신 처리
[03. Control]      MouseFlow AI ─▶ 마우스 우클릭 제스처로 작업 창들을 순식간에 정렬
[04. Compare]      ExcelCompare ─▶ 대용량 엑셀 시트의 변경점을 0.1초 만에 추적하고 원본 셀과 실시간 검증
[05. Clipboard]    QueueClip    ─▶ 복사한 순서대로 터보 자동 붙여넣기로 대량 반복 입력을 광속 처리
[06. Dispatch]     FileHub AI   ─▶ 완성된 결과물과 다운로드 파일들을 0.1초 만에 감시하여 최적 폴더로 자동 분류
[07. Gesture Drop] RadialDrop   ─▶ 드래그 중인 파일들을 360° 휠과 임시 선반에 빠르게 수납해 한 번에 이동
[08. Teleport]     QuickPath    ─▶ 파일 열기·저장 대화상자를 작업 중이던 탐색기 위치로 0.1초 만에 순간이동
```

## 💻 System Requirements (시스템 요구사항)

- **Operating System**: Windows 10 (64-bit, 1809 이상) / Windows 11
- **Architecture**: x64 최적화
- **Framework**: .NET Framework 4.8 / .NET 8.0 Runtime
- **macOS Support**: OverlayPic의 경우 macOS 11.0 Big Sur 이상 (Apple Silicon M1/M2/M3 & Intel x64) 완벽 지원
